# DIVA-5-PDF-EN-RU
The DIVA-5 (Diagnostic Interview for ADHD in Adults, version 5) is a structured clinical interview used by healthcare professionals to assess and diagnose Attention-Deficit/Hyperactivity Disorder (ADHD) in adults. Published by the DIVA Foundation, it evaluates lifetime symptoms based on official DSM-5 diagnostic criteria. Доступен на русском.
